Взаимодействие между модулями (упрощённая диаграмма)

```
[main.js] → инициализирует App.db, App.supa, проверяет kill, запускает синхронизацию
         → устанавливает обработчики auth и online/offline
         → вызывает App.events.init() и переключает на вкладку dashboard

[events.js] → слушает клики на кнопки (data-action)
           → вызывает методы страниц (App.ui.pages.*)
           → при online/offline вызывает App.db.sync.forceSync()

[store.js]   ←→ [db/indexedDB.js]   (загрузка/сохранение данных)
[store.js]   ←→ [api/storage.js]    (при онлайн-запросах обновляет и БД, и сервер)

[api/storage.js] → вызывает [api/supabase.js] (онлайн) или
                 → [state/store.js].addPendingAction (офлайн) + обновляет IndexedDB

[api/supabase.js] → напрямую общается с Supabase (через App.supabase)

[db/sync.js]   → читает pendingActions из IndexedDB, отправляет через supabase, удаляет при успехе
[db/encryption.js] → используется [store.js] при загрузке/сохранении настроек
[db/killSwitch.js] → периодически проверяет RPC, при активации уничтожает БД

[modules/moduleLoader.js] → динамический import() премиум-модулей
[modules/premium.js] → проверяет подписку, активирует ключ
[ui/pages/cars.js] → вызывает moduleLoader.load('premium/partsSearch') для VIN/номера
```

Edge Functions

Функция Вызывается из Назначение
vin-lookup partsSearch.getVehicleInfo() Декодировать VIN через NHTSA, кэшировать результат
dvla-lookup partsSearch.getVehicleInfoByPlate() Получить данные по британскому номеру (DVLA API)
rdw-lookup partsSearch.getVehicleInfoByPlate() Получить данные по нидерландскому номеру (открытое API)
parts-search partsSearch.searchPartsByVIN/OEM() Поиск запчастей через 17vin.com (требуется API-ключ)
calendar-feed cars.subscribeToCalendar() Генерация iCal для планов ТО (используется в календаре)
secure-reset-password main.js (recoverVia...) Сброс пароля через резервный код / Telegram
send-telegram-recovery main.js (recoverViaTelegram) Отправка кода восстановления в Telegram

Поток данных при офлайн-операции

1. Пользователь добавляет операцию (offline) → storage.saveOperation() видит !navigator.onLine → queueAction() добавляет запись в pending_actions IndexedDB → обновляет App.store и IndexedDB через saveOperationToDB() → показывает тост.
2. При возврате сети → событие online вызывает App.db.sync.forceSync() → sync.js читает все pending_actions, отправляет по очереди в Supabase.
3. Если сервер возвращает 409 (конфликт), загружается серверная версия и заменяет локальную (Last Write Wins).
4. После успешной отправки действие удаляется из очереди.

Шифрование

· Поля telegramToken, telegramChatId, vin, plateNumber хранятся в settings в зашифрованном виде (AES-GCM).
· Ключ шифрования получается из пароля пользователя (PBKDF2) и хранится в памяти сессии.
· При первом сохранении создаётся верификационная строка CarLoggerVerified.
· При смене пароля шифрования все секреты перешифровываются.

RLS политики (пример)

· Для всех таблиц с user_id или car_id созданы политики, ограничивающие доступ только к записям, где user_id = auth.uid() или car_id принадлежит пользователю (через cars или car_shares).
· Таблицы кэша (vin_cache, plate_cache, parts_cache) разрешают SELECT и INSERT для аутентифицированных пользователей (без привязки к конкретному пользователю).
· kill_switches доступна только для служебной роли (администратора).

4. Схема взаимодействия при поиске запчастей (пример)

```
[Пользователь вводит VIN на вкладке Автомобиль]
    ↓
cars.js → vinInfoBtn → App.modules.load('premium/partsSearch')
    ↓
partsSearch.showVehicleInfoModal(vin)
    ↓
getVehicleInfo(vin) →
    ├─ Проверка локального кэша (IndexedDB, 30 дней)
    ├─ Локальный декодер @cardog/corgi (офлайн)
    └─ Вызов Edge Function vin-lookup (NHTSA, кэширует в Supabase)
    ↓
[Отображение таблицы с характеристиками авто]
    ↓
[Premium пользователь нажимает «Найти запчасти»]
    ↓
searchPartsByVIN(vin) →
    ├─ Кэш IndexedDB (7 дней)
    └─ Edge Function parts-search → запрос к 17vin.com с токеном
    ↓
[Отображение списка OEM, цен, поставщиков]
```

Все операции кэшируются на уровне Supabase и IndexedDB для минимизации запросов к платным API.
